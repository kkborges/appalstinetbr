================================================================================
                            INICIAR O PROJETO
================================================================================

1. Instalar dependências:
   $ npm install

2. Configurar PostgreSQL com PostGIS:
   $ docker run -d --name marketplace-db \
     -e POSTGRES_PASSWORD=postgres \
     -e POSTGRES_DB=marketplace \
     -p 5432:5432 \
     postgis/postgis:15-3.4

3. Configurar .env:
   $ cp .env.example .env
   (Editar DATABASE_URL e NEXTAUTH_SECRET)

4. Executar migrations e seed:
   $ npm run db:push
   $ npm run db:seed

5. Iniciar servidor:
   $ npm run dev

6. Acessar:
   http://localhost:3000
